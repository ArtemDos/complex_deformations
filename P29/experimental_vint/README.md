# Анализ деформирования по винтовым траекториям (Эксперимент П.29)

Этот раздел содержит все необходимые файлы для проведения численного моделирования в Ansys APDL и последующего сравнительного анализа результатов с экспериментальными данными в Jupyter Notebook.

## Содержимое папки

### Основные файлы анализа
- `analysis.ipynb`: Основной Jupyter Notebook для анализа, визуализации и сравнения данных
- `bkin.ipynb`, `biso.ipynb`, `chab.ipynb`, `voce_hardening.ipynb`: Индивидуальные ноутбуки для анализа каждой модели пластичности
- `identification_chaboche.ipynb`, `identification_voce_hardening.ipynb`: Ноутбуки для идентификации параметров моделей пластичности

### Макросы ANSYS APDL
- `bkin.mac`, `biso.mac`, `chab.mac`, `voce_hardening.mac`: Макросы для проведения численных расчетов с использованием моделей упрочнения:
  - **BKIN** - кинематическое упрочнение
  - **BISO** - изотропное упрочнение  
  - **CHAB** - нелинейное кинематическое упрочнение по Шабошу
  - **Voce Hardening** - модель упрочнения Восе

### Экспериментальные данные
- `ezz_data.csv`, `ett_data.csv`, `etz_data.csv`: Экспериментальные данные по соответствующим **компонентам деформаций**
- `szz_data.csv`, `stt_data.csv`, `stz_data.csv`: Экспериментальные данные по соответствующим **компонентам напряжений**

### Параметры моделей
- `chab_params.txt`, `voce_hardening_params.txt`: Файлы с параметрами моделей пластичности
- `nu.txt`: Коэффициент Пуассона
- `filter_step.txt`: Параметры фильтрации данных

## Порядок работы

Для получения и анализа результатов необходимо выполнить следующие шаги в строгой последовательности.

### Шаг 1: Проведение численных экспериментов в Ansys

**Цель:** Сгенерировать файлы с результатами численного моделирования для каждой модели материала.

**Перед началом:** Убедитесь, что все файлы `.mac` и `.csv` (с экспериментальными деформациями) находятся в одной папке, и эта папка установлена как **рабочая директория (Working Directory)** в Ansys.

**Действия:**
1. **Запустите Ansys Mechanical APDL.**
2. Выполните в командной строке Ansys (или через `File -> Read Input from...`) макрос для первой модели:
   ```apdl
   /INPUT, bkin, mac
   ```
   Дождитесь завершения расчета. В рабочей директории будет создан файл с результатами `bkin.csv`.

3. Повторите процедуру для других моделей:
   ```apdl
   /INPUT, biso, mac
   ```
   Будет создан файл `biso.csv`.
   ```apdl
   /INPUT, chab, mac
   ```
   Будет создан файл `chab.csv`.
   ```apdl
   /INPUT, voce_hardening, mac
   ```
   Будет создан файл `voce_hardening.csv`.

**Результат:** После выполнения этого шага у вас в папке `experimental_vint` будет четыре новых CSV-файла с результатами численных расчетов.

### Шаг 2: Анализ данных в Jupyter Notebook

**Цель:** Загрузить численные и экспериментальные данные, обработать их и построить сравнительные графики.

**Перед началом:** Убедитесь, что вы настроили ваше виртуальное окружение Python, как описано в `README.md` корневого каталога проекта.

**Действия:**
1. **Откройте файл `analysis.ipynb`** в VS Code или Jupyter Lab.
2. **Выберите правильное ядро (Kernel):** Убедитесь, что в правом верхнем углу выбран ваш Kernel, например, `complex_deformations_env`.
3. **Укажите правильные пути:** В первых ячейках ноутбука, где происходит загрузка данных, проверьте и при необходимости скорректируйте пути к CSV-файлам (как к численным, так и к экспериментальным).
4. **Выполните все ячейки:** В меню выберите **`Kernel -> Restart & Run All`**, чтобы выполнить весь анализ с чистого листа.

**Результат:** Ноутбук последовательно загрузит все наборы данных, выполнит необходимые вычисления (расчет векторов Ильюшина, кривизны, крутки, угла сближения) и отобразит сравнительные графики "Расчет vs Эксперимент" для каждой из моделей.

### Шаг 3: Индивидуальный анализ моделей

Для более детального анализа каждой модели пластичности используйте соответствующие ноутбуки:
- `bkin.ipynb` - анализ модели кинематического упрочнения
- `biso.ipynb` - анализ модели изотропного упрочнения  
- `chab.ipynb` - анализ модели Шабоша
- `voce_hardening.ipynb` - анализ модели Восе

### Шаг 4: Идентификация параметров

Для автоматической идентификации параметров моделей пластичности используйте:
- `identification_chaboche.ipynb` - оптимизация параметров модели Шабоша
- `identification_voce_hardening.ipynb` - оптимизация параметров модели Восе

## Методы анализа

### Векторный анализ в пространстве Ильюшина

- Оценка относительной погрешности модуля напряжений
- Сравнение компонент тензоров деформаций и напряжений

### Скалярные характеристики
- Интенсивность напряжений по Мизесу
- Параметр Одквиста
- Пластические деформации
